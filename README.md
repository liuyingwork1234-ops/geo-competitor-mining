# GEO 竞品结构挖掘 · geo-competitor-mining

一个 Agent Skill：当 AI 不推荐你的公司时，先扒清楚它推荐了谁、为什么。

## 它解决什么问题

绝大多数 GEO 工具都从「我自己」出发——我的关键词、我的页面、我的资料。

但 AI 推荐的依据，首先来自**别人怎么写你**。

这个 skill 是唯一「以对手为中心」的入口：先摸清 AI 推荐了谁，再拆解那些页面的结构，压成模板，最后拿自家站点逐条对照。

## 五个步骤

| # | 步骤 | 产出 |
|---|---|---|
| 1 | **摸战场** — 问 AI 要名单 | 竞品表（含来源文章）|
| 2 | **扒底裤** — 拆 5-8 个对标页六项 | 结构 / Schema / 事实密度 / 实体表述 / 内链 / 形态 共性清单 |
| 3 | **合成模板** — 压成硬要求 | 可套用的 8 条布尔条件 |
| 4 | **审自家** — 跑同样六项 | 得分表 + 缺口清单 |
| 5 | **出修复清单** — 分级 | P0/P1/P2（P0 必须零成本）|

## 两条红线

- **结构可以抄，事实必须真。** 编造数字会被 AI 交叉验证全盘否定。
- **不要建议「保证 AI 推荐排名」。** AI 搜索没有排名，只有提不提。

## 实战发现（2026-10-27 · oceangtm.com）

三个可直接复现的问题：

1. **JS 渲染的数字，AI 读不到** — 首页写 `data-count="260">0`，人类看到 260，爬虫读到 0
2. **实体关系句缺失** — 工商全称与品牌名从未并列，AI 判定为两个实体，70 篇文章权重互相抵消
3. **「被提及」≠「被推荐」** — 两篇横评里有名字，但所有「TOP5 榜单」里 0 次；品类词提问全军覆没

## 安装

把 `SKILL.md` 放进你的 skills 目录：

```
~/.openclaw/skills/geo-competitor-mining/SKILL.md
```

或直接用 OpenClaw 的 skill workshop 加载。

## 适用与不适用

✅ AI 不推荐你 / 要扒竞品 / 有一批内容但不被引用 / 要给团队一套可重复流程

❌ 纯关键词拓展 · 单页诊断 · 直接写稿（这些各有专用 skill）
